\# Non-Functional Requirements



\## 1. Usability



The system should provide a simple and user-friendly interface that allows students to find relevant PYQs quickly.



\## 2. Performance



The system should return relevant search results within a reasonable response time.



\## 3. Accuracy



The system should retrieve questions that are relevant to the topic entered by the student.



\## 4. Scalability



The system architecture should support the addition of new subjects, topics, and PYQ papers in the future.



\## 5. Maintainability



The system should be modular and organized to allow future modifications and feature additions.



\## 6. Reliability



The system should provide consistent search results and handle invalid or incomplete search queries appropriately.



\## 7. Security



The system should protect stored data and restrict unauthorized access to administrative functions.
