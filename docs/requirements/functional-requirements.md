\# Functional Requirements



\## 1. Subject Selection



The system shall allow students to select a Computer Science subject from the available list of subjects.



\## 2. Topic Search



The system shall allow students to enter a topic or concept for which they want to find Previous Year Questions.



\## 3. PYQ Retrieval



The system shall retrieve questions related to the selected topic from the available PYQ database.



\## 4. Intelligent Search



The system shall use keyword matching and semantic similarity techniques to identify conceptually related questions.



\## 5. Relevance Ranking



The system shall rank retrieved questions based on their relevance to the searched topic.



\## 6. Question Metadata



The system shall display relevant information such as examination year, semester, marks, and question text.



\## 7. Topic Analysis



The system shall provide topic-wise information such as question frequency and year-wise occurrence.



\## 8. Practice Mode



The system shall allow students to practice questions retrieved for a specific topic.



\## 9. PYQ Processing



The system shall process scanned PYQ documents and extract question text for storage and retrieval.
