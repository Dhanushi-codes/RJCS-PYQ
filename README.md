# RJCS-PYQ

## An Intelligent Topic-Based Previous Year Question Retrieval and Analysis System for Computer Science Students

RJCS-PYQ is a web-based platform designed to help Computer Science students of Ramniranjan Jhunjhunwala College quickly find Previous Year Questions (PYQs) related to a specific subject and topic.

Instead of manually searching through multiple question papers, students can enter the subject and topic they have studied, and the system retrieves relevant questions from available previous year question papers.

The system aims to use Natural Language Processing and semantic similarity techniques to identify conceptually related questions, analyze question patterns, and help students prepare more efficiently.

## Objectives

- Provide a centralized platform for accessing previous year questions.
- Allow students to search PYQs based on subject and topic.
- Retrieve relevant questions automatically.
- Identify conceptually related questions using NLP and semantic similarity.
- Analyze topic-wise question frequency and patterns.
- Help students practice questions related to the topics they have studied.

## Planned Features

- Subject-wise PYQ management
- Topic-based PYQ search
- Intelligent semantic search
- Relevance-based question ranking
- Topic frequency analysis
- Year-wise question analysis
- Practice mode
- PYQ document processing
